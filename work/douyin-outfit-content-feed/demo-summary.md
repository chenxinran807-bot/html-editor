# 穿搭内容流原型交付说明

原型覆盖“按场景、适合我、博主推荐”三个平行频道，以及真人穿搭、主题合集、商品搭配三类详情。搜索会按标题、说明、显式演示作者昵称和风格标签过滤当前内容流，显示结果数与无结果清空入口；关闭搜索会清空查询。准备态且有内容时，内容流末尾明确提示已浏览完成，并按当前频道、筛选和查询提供可继续进入的本地主题推荐；合集详情也有明确末尾标记与相邻合集入口。主题首屏可直接进入合集详情，频道、筛选与滚动位置会在详情返回后恢复。

状态菜单可切换加载、空内容、加载失败、图片失败和正常内容；加载使用混合卡片骨架，已有内容后的失败提示位于内容流底部并保留卡片。清除筛选、清除搜索、重新加载、不感兴趣撤销等恢复路径均可操作；反馈失败演示会回滚并提供重试。喜欢、收藏、关注和查看搭配单品仅改变本地演示状态，不产生真实交易或推荐效果。

右下角“编辑原型”进入编辑模式。选择带虚线框的卡片、主题主视觉或详情内容块后，可在其父容器、应用宽度与视口边界内修改位置偏移和宽高尺寸；系统会记录请求值与实际夹紧值，留空会恢复原始自适应布局。应用外壳、吸顶头部、频道筛选、底部导航、按钮和全宽结构区不开放几何编辑，避免破坏移动导航。其他元素仍可按适用范围修改文字、颜色、本地图片、显隐、禁用和预览跳转；支持撤销、重做、浏览器本地持久化、修改 JSON 导出及元素级 Agent 评论导出。切回预览后编辑控件隐藏且不可操作，页面恢复正常浏览交互。

边界：无真实商品、库存、价格、登录、交易、作者或推荐服务；素材均为本地抽象 SVG。
