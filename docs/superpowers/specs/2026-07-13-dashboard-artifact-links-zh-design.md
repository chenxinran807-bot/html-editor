# 原型实验看板 Artifact 链接与中文化设计

## 目标

简化原型实验看板的信息结构：删除证据画廊，直接展示每个实验的 Artifact 入口，并将所有面向用户的看板标签改为中文。

## 信息架构

- 保留概览、两份输入的独立排名、七维评分、跨输入比较、适用性和偏离说明。
- 完全删除证据画廊区域，不再在页面中渲染证据截图缩略图。
- 新增“原型产物”区域，按输入分为“穿搭 Tab”与“相机上传”两组。
- 每个实验显示 Skill 名称、状态、总分和可直接打开的 Artifact 链接。
- `BLOCKED` 且没有 Artifact 的实验显示“暂无可打开产物”，不生成无效链接。

## 中文标签

- Overview → 概览
- Ranking → 排名
- Skill → 技能
- Total → 总分
- Status → 状态
- Artifact → 原型产物
- Cross-input → 跨输入比较
- Applicability → 适用性
- Deviations → 原生流程偏离
- Best use → 最适合
- Main weakness → 主要弱点
- Recommended scenario → 推荐场景
- Avoid scenario → 不推荐场景
- `PASS_WITH_CONCERNS` → 通过，但有关注项
- `BLOCKED` → 已阻断
- `NOT_APPLICABLE` → 不适用

Skill 的正式产品名称保留，不强行翻译。

## 数据与生成器

- `data.json` 继续保留证据路径，供报告和审计使用，但看板页面不渲染证据画廊。
- Artifact 链接由每个 `result.json` 的 `artifacts` 数组生成，使用相对路径，确保本机静态服务器可打开。
- 修改生成器而不是只修改生成后的 HTML，保证后续重建不会恢复证据画廊或英文标签。

## 验收标准

- 页面不存在“证据画廊”及证据缩略图网格。
- 12 个实验均在“原型产物”区域出现。
- 有 Artifact 的实验至少提供一个有效链接；无 Artifact 的阻断实验不产生死链接。
- 看板面向用户的栏目名、状态和操作文字均为中文。
- 排名顺序、分数、结果状态和报告数据不发生变化。
- 看板测试覆盖中文标签、证据画廊缺失、Artifact 链接数量与相对链接有效性。

## 范围外

- 不删除各实验目录中的截图或证据文件。
- 不修改实验评分、排序算法、原型内容或远程资产。
- 不发布到外部托管服务，继续使用当前本机看板。
