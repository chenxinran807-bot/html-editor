# Figma 采集助手 v2.0.2 极简首次使用设计

日期：2026-07-20  
状态：待用户书面复核

## 1. 目标

将当前需要用户理解“菜单栏 App、manifest、开发插件、上传器”的安装流程，压缩为：

- 首次使用：一个主按钮完成登录引导与插件安装引导；
- 日常使用：只在 Figma 多选 Frame 并运行插件；
- 导出、校验、上传全部后台完成；
- 成功或失败通过清楚的中文状态和 macOS 通知反馈。

## 2. 用户路径

### 2.1 首次打开

App 首页只显示一个主按钮：`安装并开始使用`。

点击后按状态自动推进：

1. 检查飞书登录；若未登录，直接显示二维码。
2. 用户扫码后，App 自动轮询授权结果，不再要求点击“我已扫码”。
3. 授权完成后，App 自动打开 Figma，并在 Finder 中打开插件目录、选中 `manifest.json`。
4. App 只保留一条明确操作说明：
   `在 Figma 选择 Plugins → Development → Import plugin from manifest…，然后选择已高亮的 manifest.json。`
5. 页面提供辅助按钮：`复制 manifest 路径`、`重新打开 Figma`。

由于 Figma 开发插件导入没有稳定、公开的一键安装接口，v2.0.2 不使用系统辅助功能模拟点击，也不声称可以自动完成该安全步骤。

### 2.2 日常使用

用户无需再主动打开 App：

1. 在 Figma 中按住 Shift 多选需要参考的 Frame；
2. 运行 `Figma Capture Kit — Batch`，点击 `采集所选页面`。

插件生成任务 ZIP 后，菜单栏 App 自动监听、校验并上传飞书。完成后发送 macOS 通知：

`已采集 3 个页面，可以让支持 prd-demo Skill 的 Agent 开始生成。`

## 3. App 状态设计

App 只呈现用户可理解的状态：

- `需要首次设置`
- `请扫码登录飞书`
- `正在确认登录`
- `请在 Figma 导入插件`
- `等待采集`
- `正在上传`
- `采集完成`
- `需要处理`

不得把命令、绝对路径、device code、JSON 或堆栈直接展示给用户。

## 4. 授权行为

- 扫码后自动调用完成授权流程；
- 遇到飞书 `authorization_pending` 时继续等待；
- 遇到 `slow_down` 时按服务端要求提高轮询间隔，默认增加至至少 10 秒；
- 授权过期时显示“二维码已过期，请重新扫码”；
- 网络错误显示“网络连接失败，请检查网络后重试”；
- 技术详情仅写入本机诊断日志，不进入主界面。

## 5. 插件安装辅助

点击安装辅助后：

- 调用系统打开 Figma；
- Finder 打开内置插件目录，并选中 `manifest.json`，而不是打开 JSON；
- 将 manifest 绝对路径写入剪贴板，方便文件选择器定位；
- 页面展示 Figma 菜单路径，不展示 code.js、ui.html 等实现文件；
- 安装文档同步使用同一套措辞。

App 无法可靠检测 Figma 是否真的导入了开发插件，因此不设置虚假的“自动检查已安装”。用户完成一次导入后，可以直接关闭窗口；后台服务继续运行。

## 6. 后台与通知

- 登录成功后自动启动上传监听并设置登录时启动；
- 关闭窗口不退出后台服务；
- 上传成功通知包含 Frame 数量，不包含设计内容和文件名；
- 上传失败通知只说明任务仍保留，并提供“打开助手”入口；
- 菜单栏保留状态入口和退出功能。

## 7. 验收标准

1. 全新用户打开 App 时只看到一个主要动作。
2. 扫码后无需再点击按钮，授权能够自动完成。
3. `slow_down` 不再显示技术错误，并能自动继续。
4. 点击插件安装辅助不会用编辑器打开 `manifest.json`。
5. Finder 会显示插件目录并选中 `manifest.json`。
6. 用户无需理解 Chrome 扩展；主流程不出现 Chrome 扩展入口。
7. 再次启动时，已登录用户直接看到“等待采集”。
8. Figma 多选导出后，App 自动完成校验和上传并发出系统通知。
9. 所有现有任务协议、SHA-256 校验和 `_COMPLETE.json` 原子完成规则保持不变。

## 8. 非目标与后续方向

v2.0.2 不包含：

- 模拟用户点击 Figma 菜单；
- 自动发布或安装社区插件；
- 修改 prd-demo Skill 消费协议；
- 重新设计 Figma 插件的批量导出能力。

后续如果获得 Figma 组织插件发布权限，可将首次插件导入替换为组织插件的一键安装链接，进一步消除开发插件导入步骤。
