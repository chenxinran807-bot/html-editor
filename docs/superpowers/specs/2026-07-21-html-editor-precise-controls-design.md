# HTML Editor 精确可视化控件设计规格

日期：2026-07-21  
状态：设计已确认，待用户复核规格

## 1. 背景与目标

当前 HTML 标注面板在 macOS Inspector 改版后出现两类问题：

1. 原有页面颜色、系统取色器和屏幕吸色入口丢失；
2. “字大一点”“文字更醒目”“上下 8 px”等按钮既笼统，又要求非设计用户理解设计术语和像素尺度。

本次优化的目标不是增加一个独立设计工具，而是继续在原 HTML 标注插件面板内，让完全不会设计、不会使用 Figma 的用户通过实时观察页面完成准确修改，并让 Agent 获得明确、可执行的标注值。

## 2. 设计原则

- **页面效果优先**：用户主要通过实时页面变化判断结果，数值只用于准确记录。
- **所见即所得**：控件操作立即作用于被选元素；取消或撤销可恢复。
- **对象相关**：选中什么，只显示与该对象相关的设置。
- **自然语言优先**：主界面使用“和旁边元素的距离”“内部留白”等说法，不暴露 `margin`、`padding` 等术语。
- **精确但不强迫理解数值**：像素、颜色值、CSS 选择器等技术字段保留在辅助位置或“高级信息”中。
- **延续现有形态**：保持附着在 HTML 页面上的 macOS 原生 Inspector 风格，不拆成独立工作台。
- **零网络依赖**：不新增外部 UI 框架、图标库、字体或网络依赖。

## 3. 整体信息架构

面板由四层组成：

1. **对象摘要**：说明当前选中的是文字、按钮、卡片或图片，并显示用户可读名称。
2. **对象相关设置**：根据元素类型动态展示核心控件。
3. **修改意见**：仍可输入自然语言补充无法用控件表达的要求。
4. **高级信息**：默认折叠，包含 CSS 选择器、精确像素值、十六进制色值等。

对象与设置映射：

| 选中对象 | 默认展示 |
|---|---|
| 文字 | 内容、字号、字重、行距、对齐、文字颜色 |
| 按钮 / 卡片 / 容器 | 尺寸、间距、内部留白、背景、边框、圆角、阴影 |
| 图片 | 替换图片、裁切方式、圆角 |
| 其他元素 | 通用尺寸、间距、外观，以及自然语言意见 |

## 4. 间距交互

### 4.1 主交互：页面直接拖拽

- 选中元素后，在其四条边显示轻量拖拽手柄。
- 默认模式为“和旁边元素的距离”。拖动某一边时，调整该方向与最近相邻元素之间的距离。
- 面板可切换为“内部留白”。切换后，同一组边缘手柄调整元素内容与边界之间的距离。
- 拖动过程中，页面实时变化，并显示参考线与当前距离。
- 松手后记录最终精确值，生成结构化标注。
- 数字不是选择前提；用户可只依据视觉效果完成操作。

### 4.2 防误触和可恢复性

- 只有当前选中元素出现手柄。
- 拖动开始后高亮实际受影响的边。
- `Esc` 取消本次拖动；完成后可通过撤销恢复。
- 当无法可靠识别相邻元素时，不猜测修改对象，改为提示用户切换“内部留白”或使用自然语言说明。

## 5. 颜色交互

颜色功能提供三个并列入口：

1. **当前页面常用颜色**：从页面实际样式中提取并去重，以色块展示；点击立即预览。
2. **屏幕吸色**：使用浏览器原生 `EyeDropper`（环境支持时），允许从页面任意位置取色。
3. **自定义颜色**：调用系统原生颜色选择器。

具体规则：

- 根据上下文明确标注“文字颜色”“背景颜色”或“边框颜色”。
- 当前颜色显示选中态。
- 色值作为辅助信息显示；用户不需要填写或理解十六进制值。
- 不支持 `EyeDropper` 时隐藏该入口，而不是显示不可用按钮。
- 颜色变化实时预览，可撤销。

## 6. 文字交互

删除“字大一点”“字小一点”“文字更醒目”等模糊快捷词，改为以下明确控件：

- **文字内容**：直接编辑真实文本。
- **字号**：`−  当前值  +` 步进器，操作时页面实时变化。
- **字重**：常规 / 中等 / 加粗。
- **行距**：紧凑 / 标准 / 宽松；实际值由当前字号与原样式映射，并在高级信息中记录。
- **对齐**：左 / 中 / 右，使用简洁的内联 SVG 图标与文字辅助说明。
- **文字颜色**：复用颜色交互。

控件的最终输出必须包含确定值，不把“更大”“更醒目”作为 Agent 的执行指令。

## 7. 外观交互

外观设置采用可实时预览的有限选项：

- 背景颜色、文字颜色、边框颜色；
- 圆角：直角 / 小圆角 / 大圆角 / 胶囊；
- 边框：无 / 细 / 粗；
- 阴影：无 / 轻 / 明显。

有限选项负责降低使用门槛，最终记录中仍保存对应的确定 CSS 值。若原元素存在不在预设中的数值，界面显示“当前”，不擅自归类或覆盖。

## 8. 图片交互

选中图片时只展示：

- 替换图片；
- 裁切方式：完整显示 / 填满区域；
- 圆角；
- 添加参考图。

图片替换与参考图必须保持现有数据输出和对话附件能力，不因面板改版丢失。

## 9. 视觉与可用性

- 视觉参考 macOS 系统设置、访达 Inspector 和原生 Popover。
- 使用系统字体栈、灰阶层级、8px 基础节奏和清晰分组。
- 图标使用自带内联 SVG，不使用 Emoji。
- 主控件最小点击高度 32px；拖拽手柄提供足够命中区域，但视觉保持克制。
- 面板避免横向溢出；小屏时内部滚动，不遮挡当前选中元素的关键区域。
- 技术信息默认折叠，保证首次使用者先看到“能做什么”。

## 10. 数据输出

每次控件修改同时产生两类信息：

1. 用户可读摘要，例如“将卡片右侧与相邻卡片的距离调整为当前效果”；
2. Agent 可执行结构化值，例如目标选择器、属性、修改前值、修改后值、单位和作用方向。

结构化数据必须区分：

- `external-spacing`：和旁边元素的距离；
- `internal-spacing`：内部留白；
- `text`：内容、字号、字重、行距、对齐；
- `appearance`：颜色、边框、圆角、阴影；
- `image`：来源、裁切和圆角。

现有自然语言标注、参考图、导出和退出标注流程保持兼容。

## 11. 状态与异常处理

- **未选中**：说明“点击页面中想修改的内容”。
- **已选中**：展示对象相关设置。
- **预览中**：页面实时变化，面板显示撤销入口。
- **已记录**：标注列表中的条目包含用户摘要和确定值。
- **能力不可用**：隐藏不可用入口并提供替代方式，例如无屏幕吸色时仍保留页面色块与系统取色器。
- **元素失效**：若 DOM 更新导致目标消失，停止修改并提示重新选择，不把修改应用到相似元素。

## 12. 验收标准

1. 页面色块、系统取色器和支持环境下的屏幕吸色均可用。
2. 面板内不再出现 Emoji 图标和“字大一点”等模糊执行按钮。
3. 非设计用户不理解 px、margin、padding，仍能通过拖拽和实时预览完成间距调整。
4. 拖动外部距离与内部留白时，作用对象和方向清晰，不互相混淆。
5. 文字、按钮/卡片、图片三类元素只展示相关设置。
6. 每次视觉操作都输出确定、可回放的结构化值。
7. 撤销、取消、参考图、标注列表、导出等既有能力无回归。
8. 无外部网络资源时，面板可完整加载和使用。
9. 桌面宽屏与窄窗口下均无明显遮挡、溢出或不可点击控件。
10. 现有自动化测试通过，并新增颜色恢复、上下文控件、拖拽间距和结构化输出测试。

## 13. 本轮明确不做

- 不建设独立设计工作台；
- 不引入完整 CSS 编辑器；
- 不要求用户学习 Figma 或设计术语；
- 不自动推断并批量修改多个相似元素；
- 不引入外部框架、字体、图标库或在线服务。
