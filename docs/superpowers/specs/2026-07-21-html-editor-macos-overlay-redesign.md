# html-editor macOS 原生浮层改版设计

日期：2026-07-21  
状态：待用户书面复核

## 1. 目标

重构 `html-editor` 的标注界面，使完全不懂设计、Figma、HTML 或 CSS 的用户也能在生成页面中指出位置、表达要求并把修改交回 Agent。

本次只重构注入页面的标注交互层与视觉语言，不改变 `html-editor` 作为 HTML 注入 Skill 的形态，也不把它改造成独立桌面工具。

## 2. 核心原则

1. 原 HTML 页面始终是视觉主体，标注器只是覆盖其上的轻量浮层。
2. 界面参考 macOS 原生 Inspector、分组列表和紧凑工具条，而不是仿制独立 macOS 窗口。
3. 用户只需完成“指出位置 → 说出要求 → 保存修改 → 完成标注”。
4. 界面使用用户语言；技术信息只进入机器可读导出内容。
5. 所有图标使用统一的内联 SVG，不使用 emoji、图片字体或外部运行时依赖。
6. 逐步呈现能力，默认状态只显示当前任务所需操作。

## 3. 主交互流程

### 3.1 默认状态

页面底部显示紧凑浮动工具条：

- `标记修改`
- `我的修改 N`
- `完成标注`

主操作为 `标记修改`，使用 macOS 系统蓝。工具条不得遮挡页面底部关键内容；在小屏幕上允许横向紧凑或折叠文字，但三个任务必须可达。

### 3.2 选择内容

点击 `标记修改` 后，出现一次性提示：

`点击页面上想修改的文字、图片或区域。`

保留现有两种选择方式：

- 点击选择单个元素；
- 拖拽框选区域。

选中内容使用系统蓝描边和低透明度外发光；已有标注使用红色数字 pin。标注模式必须继续在捕获阶段阻止页面原交互误触。

### 3.3 添加修改

选中后，在页面右下方或选区附近显示 macOS Inspector 风格浮动面板。面板不能脱离原页面成为独立工作台。

面板结构：

1. 标题：`添加修改`
2. 人类可理解的选中对象描述，例如：`已选中：中间的穿搭推荐卡片`
3. 主问题：`你希望这里怎么调整？`
4. 自然语言输入框
5. 常用操作分组：
   - `修改文字`
   - `更换图片`
   - `调整位置或大小`
   - `参考其他样式`
6. 次操作：`添加参考图`
7. 主操作：`保存修改`

快捷入口必须使用动作表达，禁止使用“文字不对、图片不对、改样式、调布局”等模糊或专业表述。

### 3.4 快捷操作二级内容

- `修改文字`：改文字内容、字大一点、字小一点、文字更醒目；
- `更换图片`：上传参考图片、说明想要的图片内容；
- `调整位置或大小`：向上/下/左/右移动、变大、变小、调整间距；
- `参考其他样式`：添加参考图，并允许补充自然语言说明。

二级内容只在用户点击相应入口后展开。用户始终可以忽略快捷入口，仅用自然语言完成标注。

### 3.5 保存与继续

保存后：

- 面板关闭；
- 页面对应位置显示红色数字 pin；
- 轻量提示 `修改已保存`；
- 工具条主操作变为 `继续标记`；
- `我的修改 N` 数量即时更新。

## 4. 我的修改

原“标注列表”改名为 `我的修改`。

每条记录只显示：

- 数字编号；
- 人类可理解的位置或对象名称；
- 用户的修改要求；
- `编辑` 和 `删除`。

不显示 CSS 选择器、HTML 标签、元素片段、页面内部 ID 或参考图文件名。技术字段继续保存在标注数据中。

列表底部操作：

- `返回继续标记`
- `完成标注`

## 5. 完成标注

原“导出”改名为 `完成标注`。

点击后：

1. 沿用现有序列化协议，生成包含页面、选择器、片段、批注与参考图数据的机器可读文本；
2. 自动尝试复制到剪贴板；
3. 用户界面只显示：
   - `修改要求已经准备好`
   - `回到 Agent 对话，粘贴并发送`
   - 主按钮 `复制修改要求`
4. 复制失败时展示一个可手动复制的文本框。

第一版接受一次复制粘贴，不建设自动回传 Agent 的服务。

界面不得出现“导出、CSS 选择器、HTML 片段、base64、重新下载参考图”等术语。参考图文件下载仍可作为失败兜底，但放入次级帮助入口，不作为主流程。

## 6. macOS 原生视觉规范

### 6.1 视觉语言

- 字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`；
- 主色：macOS 系统蓝 `#0A84FF`，并提供浅色模式下的可读性调整；
- 危险/标注色：系统红 `#FF453A`；
- 面板：高不透明度浅色材质、1px 中性边框、克制阴影；
- 圆角：工具条 13px、Inspector 14px、分组列表 9px、按钮 7px；
- 交互尺寸：桌面最小 28px，触屏最小 44px；
- 图标：统一 24×24 viewBox 的线性内联 SVG，笔画、端点和转角一致。

### 6.2 层级

- 页面内容层；
- 选区描边和标注 pin 层；
- 底部工具条；
- 当前 Inspector；
- 确认弹窗与 toast。

所有标注层继续使用 `data-annotator="true"`、`annotator-` class 前缀及 `ann-` id 前缀，避免污染页面样式和选择器。

### 6.3 响应式

- 桌面：Inspector 优先靠近选区并保持在视口内；
- 窄屏/移动端：Inspector 切换为底部 sheet；
- 键盘弹出时保证输入框和保存按钮可见；
- 标注模式下保留现有 Pointer 事件支持；退出标注后恢复页面滚动。

## 7. 用户语言与错误处理

- 未选中内容：`请先点击页面上想修改的位置。`
- 元素已变化：`原来的位置已经变化，请重新选择。`
- 没有修改：`还没有添加修改。`
- 参考图过大：自动压缩，不要求用户处理文件大小；完全失败时提示重新选择。
- 剪贴板受限：`没有自动复制，请在下面手动复制。`
- 本地存储不足：保留文字标注并提示参考图需要重新添加。

错误主界面不得展示异常栈、选择器、浏览器 API 名称或原始 JSON。

## 8. 必须保持兼容的底层能力

- 注入而非改写原 HTML；
- 幂等注入与 `--force` / `--replace` 升级；
- IIFE 隔离和命名空间隔离；
- 捕获阶段事件拦截；
- 点击与拖拽框选；
- 稳定唯一选择器生成；
- 标注 localStorage 持久化及页面变化恢复；
- 多页 `.page` / `.active` pin 跟随；
- 参考图压缩、内嵌、下载兜底；
- Clipboard API 与 textarea fallback；
- 现有机器可读导出协议字段和语义。

## 9. 验收标准

1. 注入后的可见界面不包含 emoji。
2. 零设计基础用户在无说明情况下能完成第一条标注。
3. 页面上同时只有一个明确主操作。
4. 用户界面不显示 CSS 选择器、HTML 片段和 base64。
5. 点选、框选、编辑、删除、持久化、复制和参考图能力全部通过回归。
6. 旧版已注入页面可用 `--force` 升级，不重复注入。
7. 标注层不改变原页面布局、样式和业务交互；退出标注模式后页面正常工作。
8. 桌面与移动视口均能完成完整流程。
9. 导出文本仍能被现有 Agent 精确解析并回改对应元素。
10. 快照与人工检查确认视觉符合 macOS 原生 Inspector 浮层方向，而非独立工具窗口。

## 10. 非目标

- 不改造成 Electron 或 macOS 独立应用；
- 不增加 Figma 依赖；
- 不改变 prd-demo 或 Figma 采集协议；
- 不实现标注自动回传 Agent；
- 不引入外部 UI 框架、图标库、字体或网络依赖。
