# Douyin Mall Outfit Tab Full Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained, high-fidelity, interactive 390px mobile prototype for the Douyin Mall outfit tab, covering personalization, outfit rationale, AI restyling, alternatives, and simulated AI try-on.

**Architecture:** Create a new isolated prototype under `work/douyin-outfit-full-experience/`. A single `index.html` owns rendering and styles, while focused ES modules own catalog data and the deterministic state reducer. Browser QA drives the real UI; reducer tests cover state restoration and failure/retry behavior.

**Tech Stack:** HTML5, CSS custom properties, vanilla ES modules, inline/local SVG assets, Node.js built-in test runner, Playwright browser QA.

- [ ] **Step 3: Implement catalog exports and the reducer contract**

```js
export function createInitialState() {
  return {
    screen: 'feed', channel: 'forMe', detailId: null,
    conditions: { scene: [], height: [], shape: [], skin: [], style: [] },
    filtersByChannel: { scene: '日常', forMe: '推荐', creators: '精选' },
    scrollByChannel: { scene: 0, forMe: 0, creators: 0 },
    liked: [], saved: [], followed: [], hidden: [], undo: null,
    restyle: { mode: 'keep-item', anchorProductId: null, candidateId: null },
    tryOn: { status: 'idle', candidateId: null, photoId: 'demo-neutral-1' },
    toast: null
  };
}

export function reduce(state, action) {
  switch (action.type) {
    case 'SAVE_CONDITIONS': return { ...state, conditions: action.value, screen: 'feed' };
    case 'SET_CHANNEL': return { ...state, channel: action.value };
    case 'SET_SCROLL': return { ...state, scrollByChannel: { ...state.scrollByChannel, [state.channel]: action.value } };
    case 'OPEN_DETAIL': return { ...state, screen: 'detail', detailId: action.outfitId };
    case 'BACK': return { ...state, screen: state.screen === 'detail' ? 'feed' : 'detail' };
    case 'START_TRYON': return { ...state, screen: 'tryon', tryOn: { ...state.tryOn, status: 'processing', candidateId: action.candidateId } };
    case 'TRYON_FAILED': return { ...state, tryOn: { ...state.tryOn, status: 'failed' } };
    case 'RETRY_TRYON': return { ...state, tryOn: { ...state.tryOn, status: 'processing' } };
    default: return state;
  }
}
```

Extend the reducer with named actions for `TOGGLE_LIKE`, `TOGGLE_SAVE`, `TOGGLE_FOLLOW`, `HIDE_CARD`, `UNDO_HIDE`, `OPEN_CONDITIONS`, `OPEN_RESTYLE`, `SET_RESTYLE_MODE`, `SELECT_CANDIDATE`, `TRYON_DONE`, `OPEN_RESULT`, and `REPLACE_PRODUCT`. Keep every transition pure.
