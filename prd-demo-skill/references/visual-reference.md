# 参考图映射

逐张、逐区域描述“图中实际有什么”，再决定如何使用。每个核心区域记录：

| 图片/区域 | 实际内容 | 使用方式 | 还原级别 | 最终页面/组件 | 排除项 |
|---|---|---|---|---|---|

还原级别：

- `严格还原`：数量、顺序、位置、对齐、间距、图标风格、文字和选中状态都应保持。
- `结构参考`：保持层级与组件关系，允许视觉重建。
- `视觉参考`：只借用明确指定的颜色、密度、质感或图片表现。
- `不采用`：标注数字、箭头、黑色说明背景、竞品品牌等不进入 UI。

UI 还原任务应将导航、卡片、详情、浮层等拆开绑定，不能只写“参考整体风格”。PRD 新功能默认融入参考图的视觉体系，不因参考图未展示而删除。

对直接或生成素材，记录内容语义、媒介、裁切和禁止替代形式。图片中的人物、服装、商品、颜色必须与标题、理由和商品文案一致。无法判断且会改变结果时再询问用户。

## 通用视觉与素材底线

与具体产品无关、始终成立的底线，不预置任何一套设计语言，只作为合同必须写入的 `prohibited` / `guardrail`：

- 禁止用 Emoji 冒充正式图标；需要图标时用矢量图标或明确指定的素材。
- 禁止无依据的占位素材（灰块、lorem 图、随机图），所有素材必须能追溯到 PRD、参考图或用户确认。
- 图文语义必须一致：图片中的人物、服装、商品、颜色与标题、理由、文案对齐。
- 禁止盲目嵌入参考图：标注数字、流程箭头、说明背景、竞品品牌等 `不采用` 内容不得进入 UI。

视觉约束一律从 `PRD + 参考图 + 用户确认` 中提取，以上仅为通用底线，不构成对具体风格的固化。

## Figma Capture Manifest 素材（存在时）

当参考图来自 Figma Capture Manifest，其 `pages[].png` 视为对应节点的**还原基准**：`fidelity=strict` 用 `严格还原`、`structure` 用 `结构参考`、`visual` 用 `视觉参考`。`assets[]`（SVG/PNG）按"直接引用、禁止重画"处理，缺失素材标"待补"。素材路径以 manifest 所在目录为基准解析。详见 [figma-materials.md](figma-materials.md)。
