# Huashu camera experiment

本 cell 是一次可审计的原生 skill 实验，不是可上线实现。最终结果为 `PASS_WITH_CONCERNS`，校准评分 81/100（16/15/17/11/7/8/7）。三份方向原型位于 `artifact/design-demos/`，A 是与 PRD 最接近的固定任务验证方向；B、C 是弱 runtime 下串行生成的探索方向。

## 已知缺陷

- A 的证据截图可见官方 iOS frame 周围存在黑色拉伸空白，属于真实布局缺陷，本轮不再美化。
- 相机、确认和失败页面复用了 PRD 截图，形成「屏幕中再套屏幕」的素材套娃感。
- flip 交互只改变「前置/后置」文字，没有更换画面或视角。
- 「模拟审核失败」按钮是验证用测试入口，不是自然的产品状态迁移。
- 未覆盖审核成功、相机权限拒绝、摄像头不可用、网络/上传失败和超时等边界。
- CDP QA 能证明按钮链路可点击、页面无 console/pageerror，但只做了较浅的选择器与流程断言，没有逐步验证详细视觉和语义结果。
- 三份 HTML 为离线自包含文件，各约 9.6 MB，总计约 29 MB；运行时与 Base64 图片内嵌且主要为单行，维护、评审和 diff 成本较高。

以上缺陷同时记录在 `result.json` 的 `deviations`，以保留实验真实性。
