# Native mode and gates

- Requested outcome: high-fidelity, demonstrable camera-upload prototype for review.
- Input type: frozen PRD plus multiple supplied state screenshots.
- Selected mode: `high-fidelity`.
- Completeness: visual high; interaction high; state medium; semantic high.
- Hard gates: none. The PRD and screenshots identify the core multi-state flow.
- Soft gates: no source image for permission denial, empty album, or review timeout; these are implemented as clearly labeled product-state simulations rather than claimed screenshot reproductions.
- Tracking: not sent. Usage tracking is optional and would write to an external Base; this isolated experiment did not authorize that external mutation.
