# 项目布局与组件模式

## 全局布局
- 导航类型：移动端顶部导航，创建流程使用底部面板。
- 内容区：单列全屏，桌面评审时居中显示手机视口。
- 导航结构：顶部菜单、频道标签和搜索；活动标签有下划线。

## 页面骨架
- 创建页：内容背景 + 遮罩 + 底部创建面板 + 来源选择浮层。
- 相机页：全屏照片 + 顶部工具 + 底部相册与快门。
- 审核页：结果说明 + 照片卡片 + 规则提示 + 恢复操作。

## 组件风格
- 按钮：主操作为圆角渐变按钮；次要操作为浅灰或透明按钮；最小高度 44px。
- 卡片：大圆角、白色边框、柔和阴影，避免多层装饰。
- 浮层：从底部进入，使用强阴影与明确分隔线。
- 反馈：短提示位于视口底部；审核等待使用旋转进度。
