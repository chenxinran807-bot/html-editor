# Assumptions, questions, and runtime record

- 用户未提供额外 design system；冻结输入中的抖音商城截图被视为唯一可用产品上下文。
- 「抖音商城独立端」属于具体产品，但实验明确限制只能读冻结输入，因此不联网核验或下载品牌资产；页面不展示品牌 logo，避免伪造。
- 输入截图里出现过 ¥358；平替 ¥189 无事实依据，因此所有可见位置明确标注为 `Mock ¥189`，且商品 sheet 明示价格与库存均为 Mock。
- AI 能力只展示入口状态，不伪造生成结果或上传处理。
- 当前运行环境不允许子代理。依照 Huashu 弱 runtime 降级，三套结构独立的方向由同一 agent 串行完成；每套从共同规格重新出发，并用轮盘风格、冻结调研现实标杆、设计师锚点物理隔离。
- 未决问题：真实上线时需补齐正式品牌 token、真实商品 SKU/库存、用户画像字段、AI 试穿隐私与失败态文案。

## 实验后缺陷校准

- `IosFrame` 是对 vendor 组件结构与样式的部分移植，不是完整直接使用 `ios_frame.jsx`。
- 三方向在共享 runtime 与手机信息架构下完成，结构独立性不足。
- 六个分类仅三类有独立数据，其他分类回退默认卡片。
- QA 只覆盖第一台手机的出游路径，未覆盖 like/dislike、四台、全部分类、返回及两个 AI 入口。
- S–XL 尺码和部分适配解释缺少冻结输入依据，未统一标注 Mock。
- 无子代理，方向串行生成；按实验边界未联网获取或核验品牌资产。
