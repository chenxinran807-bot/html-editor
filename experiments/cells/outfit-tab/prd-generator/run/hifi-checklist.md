# High-fidelity checklist

- [x] Mobile product shell, not prototype viewer chrome
- [x] Local imagery and real-format content
- [x] Primary journey controls are interactive
- [x] Hover/focus/active and selected states
- [x] Card elevation and content hierarchy
- [x] Suitability/formula/avoidance panels
- [x] Product size, purchase, same/alternative states
- [x] Like and dislike feedback
- [x] Loading, empty, error and retry states
- [x] No remote runtime asset dependency
- [x] Cross-state visual consistency
