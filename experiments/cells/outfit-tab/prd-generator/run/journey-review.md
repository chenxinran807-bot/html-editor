# 阶段二：旅程走查

1. 入口：默认博主精选；首次用户不宣称个性化。
2. 分类：切到场景/身型后内容、理由和选中态同步；加载失败可重试，空结果可回推荐。
3. 决策：用户从理由卡判断是否点开；喜欢/不喜欢改变反馈状态，不阻断主线。
4. 理解：详情依次回答适合谁、怎么搭、如何避雷。
5. 承接：同款与平替明确区分；商品显示价格/材质/尺码，选择和购买有反馈。
6. 个性化：保留商品继续搭或携带整套进入试穿；上传进入照片审核准备态。
7. 返回：商品和 AI 状态均可返回详情，保持上下文。

确认推断依据：冻结输入明确了四模块、一期验收、P0-P2 分期和固定 QA tasks；以上补全仅覆盖其必需状态，不改变核心范围。

Tracking 判断：需要。目标与各段点击/停留强相关，需记录分类、卡片、详情到达、商品与 AI 漏斗。
