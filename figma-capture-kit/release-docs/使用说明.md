# 使用说明

## 一次安装

首次使用只做一次：打开“Figma 采集助手”完成飞书授权，并按安装向导把“Figma Capture Exporter”导入 Figma。以后不需要重复安装或登录。

## 日常两步

### 第一步：在 Figma 采集

1. 打开有编辑权限的 Figma 文件或个人 Drafts 副本。
2. 一次选中所有需要参考的 Frame；按住 Shift 可多选。
3. 运行“Figma Capture Exporter”，点击“导出所选 Frame”。

插件会一次生成一个任务包。菜单栏助手发现任务后，会自动校验并上传飞书；出现“上传成功”即完成，不需要手动整理文件。

### 第二步：让 Agent 生成

在兼容的 Agent 中输入：

> 使用 prd-demo Skill，根据我刚采集的 Figma 任务生成高还原交互 Demo。

Agent 应自动读取当前用户最新、完整且校验通过的任务。若同时存在多个任务，以 `_COMPLETE.json` 已完成且完成时间最新的一批为准。

兼容的 Agent 需要能够访问当前用户的飞书云空间并安装 `prd-demo` Skill。如果 Agent 没有飞书云空间能力，把任务文件夹链接或 ZIP 交给它，也能按同一 manifest 协议生成。

## 什么叫“一批”

同一次多选并导出的 Frame 共用同一个 taskId，视为一个设计任务。不同 Figma 文件或不同时间再次导出，会形成新的任务，不会和上一批混在一起。

## 当前能采集什么

- 多个 Frame 的 2× PNG；
- 整页 SVG 与可直接引用的 SVG 素材；
- Frame 名称、nodeId、尺寸、顺序与文字内容；
- unified manifest、文件哈希及完整任务标记。

当前版本不会自动理解页面跳转关系；生成前 Agent 仍会根据 PRD 或用户说明确认交互。
