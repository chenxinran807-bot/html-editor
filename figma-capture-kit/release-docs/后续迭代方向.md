# 后续迭代方向

## P0：稳定性与可追溯

- 在任务中补齐 Figma fileKey 和文档快照版本；
- 统一 `_COMPLETE.json` 文件数量口径；
- 为素材直接写入 sha256 和复用关系；
- 过滤设计稿注释、占位文案和无效图层；
- 完成 Apple 企业签名或 Developer ID 公证，消除首次启动拦截。

## P1：消费闭环

- prd-demo 自动选择当前用户最新、完整、未消费任务；
- 生成后写入 consumption 回执，记录 sessionId、Demo 地址和消费时间；
- 菜单栏助手显示“已被 Agent 消费”和 Demo 入口；
- 对重复任务、跨文件任务和过期任务提供明确提示。

## P2：高保真增强

- 补充组件状态、浮层、抽屉、空态等批量采集模板；
- 更完整地提取 variable/style token 与图层元数据；
- 自动识别页面角色和交互关系，但保留人工确认；
- 建立生成结果与参考 Frame 的视觉回归评分。

迭代原则：保持“多采集器、单协议”。任何新增能力必须通过 capabilities 明示，消费端不得把未采集误判为设计中不存在。
