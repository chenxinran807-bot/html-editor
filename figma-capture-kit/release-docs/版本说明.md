# 版本说明

## v2.0.1

- 修复飞书设备授权返回 `verification_url` 时二维码无法生成的问题；
- 内置并锁定 lark-cli 1.0.72，不再依赖构建机上的全局旧版本；
- 二维码改为安全的内嵌图片显示，授权异常会明确提示并允许重试；
- Agent 文案改为通用表述，不再限定 Aime。

## v2.0.0 MVP

这是首个冻结的内部可交付版本。

主要能力：

- Figma 插件支持多选 Frame 一次批量导出；
- 输出统一 manifest v2.0.0，并显式声明采集能力；
- 同批 Frame 由唯一 taskId 绑定；
- 本机菜单栏助手自动监听、校验并上传飞书；
- 首次启动支持飞书扫码授权；
- 文件全量 SHA-256 校验，`_COMPLETE.json` 最后上传；
- 提供设计师安装说明、两步使用说明和故障排查；
- 保留 Chrome 兜底扩展，但不作为推荐路径。

兼容环境：macOS Apple 芯片。当前为公司内部未签名安装包。
