# 常见问题

## 为什么既有 Figma 插件，又有菜单栏 App？

Figma 插件负责准确读取并导出选中的 Frame；菜单栏 App 负责监听导出结果、校验文件并上传飞书。Figma 的安全边界不允许插件可靠地代替本机程序长期监听文件，也不适合在插件里保存飞书授权，因此两者分工更稳定。

## 我在 Figma 里选了多个 Frame，为什么插件提示未选中？

请确认选中的是 Frame 本身，而不是 Frame 内部的文字、图片或多个零散图层。可从左侧图层面板按住 Shift 选中多个 Frame，再运行插件。

## 没有编辑权限怎么办？

先将文件复制到个人 Drafts，再在副本中运行插件。复制后拥有副本编辑权限，不会修改原文件。

## 为什么首次启动要扫码？

菜单栏助手需要以你的飞书身份上传私有设计任务，并让 Agent 在同一身份下读取。扫码凭证保存在本机，不写进安装包。

## Agent 怎么知道读取哪一个 Figma？

它不是读取“当前浏览器标签页”，而是读取当前飞书用户最新完成的采集任务。一次导出的多个 Frame 共享 taskId；`_COMPLETE.json` 是任务上传完毕的唯一标志。

## 上传失败怎么办？

点击菜单栏 `F` 查看错误。优先检查网络、飞书登录状态和磁盘空间；重新授权或再次导出不会覆盖旧任务。

## macOS 提示应用来自身份不明开发者

这是内部未签名包的预期行为。前往“系统设置 → 隐私与安全性”点击“仍要打开”。不要从非内部可信渠道获取此包。

## Chrome 扩展还要安装吗？

不用。`Chrome兜底扩展` 只保留给无法运行 Figma 插件的特殊情况，画质和素材能力低于主路径。
