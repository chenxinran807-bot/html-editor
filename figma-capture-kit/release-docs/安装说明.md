# Figma 采集助手安装说明

适用环境：公司内部 macOS（Apple 芯片）、Figma 浏览器版或桌面版。

## 第一次安装

1. 解压 `Figma采集助手-MVP-v2.0.1-arm64.zip`。
2. 将 `Figma采集助手.app` 拖入“应用程序”，然后打开。
3. 若 macOS 提示无法验证开发者：打开“系统设置 → 隐私与安全性”，找到被拦截的应用并点击“仍要打开”。这是内部未签名版本的正常提示。
4. 菜单栏出现 `F` 图标后，按窗口提示使用飞书扫码授权。授权只用于把采集任务上传到当前用户的飞书云空间。
5. 点击“打开 Figma 插件目录”。在 Figma 中进入“插件 → 开发 → 从 manifest 导入插件”，选择该目录内的 `manifest.json`。

安装完成后，助手会随登录自动启动。Figma 插件只需导入一次。

## 安装成功的标志

- 菜单栏能看到 `F` 图标；
- 助手显示“已连接飞书”或“等待采集”；
- Figma 的“开发中的插件”里能看到“Figma Capture Exporter”。

## 卸载

退出菜单栏助手，将“应用程序”里的 `Figma采集助手.app` 移到废纸篓；如不再使用，可在 Figma 的开发插件列表中移除插件。
