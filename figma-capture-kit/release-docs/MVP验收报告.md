## MVP 验收范围

- 多选 Frame 一次打包；
- PNG、SVG、文字及节点信息采集；
- 单 taskId 绑定同批 Frame；
- 本机自动校验和飞书上传；
- `_COMPLETE.json` 原子完成信号；
- Agent 依据统一协议读取；
- 提供素材禁止重新绘制；
- 私有设计素材按当前飞书用户身份处理。

## 已知边界（不阻塞 MVP）

- Figma 文件稳定 fileKey 与文档版本溯源仍待增强；
- 注释或占位文字的自动过滤仍待增强；
- Agent 自动选择最新未消费任务及消费回执属于后续能力；
- 当前内部包未做 Apple 签名与公证；
- Chrome 扩展仅为兜底，不作为高保真主路径。
