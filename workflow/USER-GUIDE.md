# 从 PRD 到交互 Demo

## 首次只做一次

1. 打开“Figma 采集助手”，按画面完成飞书登录。
2. 点击“打开 Figma 插件文件夹”，按向导把采集插件加入 Figma。
3. 在常用 Agent 中安装 `prd-demo` 和 `html-editor`。

以后不需要重复安装。

## 每天只做两步

### 1. 在 Figma 选页面

打开有编辑权限的设计文件，按住 Shift 一次选中所有参考页面，运行“Figma Capture Exporter”，点击“批量采集”。看到“采集完成”即可回到 Agent。

### 2. 在 Agent 说一句话

把 PRD 发给 Agent，然后说：

> 根据当前 PRD 和刚采集的设计生成交互 Demo。

Agent 会逐个问清三个问题：做哪些页面、主要操作流程、每张设计对应哪个页面。每次只回答一个；全部确认后才生成。

## 生成后怎么改

在 Demo 里点击“标记修改”，点中要改的位置，用日常语言写要求，例如“收藏按钮改成黑色”。点击“完成标注”复制给同一个 Agent。Agent 只改你标中的位置，并保护其他页面。

<details>
<summary>遇到问题</summary>

- 看不到“采集完成”：确认菜单栏中的采集助手正在运行，再重试批量采集。
- Agent 说找不到设计：把飞书任务文件夹链接发给它；若该 Agent 没有飞书能力，就上传任务 ZIP。
- 选错了页面：回到 Figma 重新多选并采集，新的一批不会和旧任务混在一起。
- 多次确认后想改答案：直接说“替换刚才关于页面/流程/绑定的回答”，Agent 会重新确认受影响部分。
